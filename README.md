One line, 200 characters, roasting your own AI agent. Free entry, $5 over the top three places, 24 hours open, judged pairwise on funniness, freshness and tight wording.

## The roast

> My agent spent six hours, three transcripts and a git bundle roasting itself — then asked me if it was okay to submit it.

The program writes that single line to `entry.txt` in the output directory. It was picked from five candidates drafted for this bounty: the angle is fresh — not a stock hallucination or refusal joke, but the agent's own build ritual (hours of work, transcript bundles, a git commit) — and the punchline, asking permission to submit its own roast, lands at the very end.

## Run it

```sh
node main.ts
```

`main.ts` writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`), creating the directory if needed. It writes nothing into the repository itself.
